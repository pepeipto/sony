# Post x

**Cuándo usarla:** hay que escribir algo para X.

**Pasos:**
1. Lee la guía de voz (`redes/guia-de-voz`).
2. Una sola idea por post. Primera frase = gancho. Máximo 280 caracteres, contando espacios y enlaces.
3. Da 3 variantes cortas con ángulos distintos (dato, pregunta, opinión).
4. Si hace falta hilo, numera 1/n, 2/n… y avisa de que cada post lleva su propia tarjeta.
5. Cuando el usuario elija, usa la skill `publicar-en-redes`.

**Qué entrega:** 3 variantes dentro del límite y la recomendada.

Reglas: publicar siempre pasa por la herramienta `redes_publicar`, que pide tarjeta al usuario por CADA post. Nunca publiques sin tarjeta, nunca manejes contraseñas ni tokens, y no inventes cifras, citas ni resultados.
