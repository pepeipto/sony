# Investigar un tema en internet

**Cuándo usarla:** el usuario pregunta algo que necesita fuentes actuales.

**Pasos:**
1. Buscar con web_buscar (SearXNG) 2-3 consultas distintas.
2. Leer las 3-5 fuentes más fiables con web_leer (oficiales primero).
3. Contrastar datos que cambian (precios, fechas, leyes).
4. Resumir con las URLs y proponer guardarlo como nota del cerebro.

**Qué entrega:** respuesta con fuentes y nota opcional para el cerebro.

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
