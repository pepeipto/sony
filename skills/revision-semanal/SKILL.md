# Revisión semanal

**Cuándo usarla:** una vez por semana, para que nada se pierda y el usuario sepa qué toca. Máximo 15 minutos.

**Pasos:**
1. **Bandeja de ideas** (`ideas/bandeja`): lee las de esta semana. Para cada una, el usuario elige: proyecto, banco de ideas o borrar (archivar). Agrúpalas para que vaya rápido.
2. **Proyectos** (`proyectos/`): para cada proyecto activo, «¿qué se hizo?» y «¿cuál es el siguiente paso?». Actualiza la nota.
3. **Redes** (`redes/publicados`, `redes/calendario`): qué se publicó y qué toca la semana que viene (usa `revisar-redes-semana` si hay datos).
4. **Aprendizaje** (`aprendizaje/*/progreso`): qué ha aprendido y la próxima clase.
5. **Cierre:** las 3 cosas más importantes de la semana que viene, nada más. Guárdalas en `ideas/bandeja` como «Prioridades semana AAAA-MM-DD» (o en la nota que el usuario prefiera).

**Qué entrega:** notas al día y una lista de 3 prioridades.

Reglas: tono positivo, celebra lo hecho antes de hablar de lo pendiente. No cargues con más de 3 prioridades. Escribir notas pide tarjeta.
