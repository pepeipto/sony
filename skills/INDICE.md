# Skills de Sony

## Propias de Sony
- analisis-competencia: Analizar la competencia. Antes de lanzar algo o para mejorar un producto.
- analisis-hoja-ventas: Analizar una hoja de cálculo o de ventas. El usuario comparte una hoja (Google Sheets o CSV) y quiere entenderla.
- auditoria-seo-local: Auditar el SEO local de un negocio. Un cliente quiere saber por qué no le encuentran en Google.
- automatizacion-n8n: Diseñar una automatización con n8n. Una tarea repetitiva que se puede automatizar.
- captar-cliente-web: Captar un cliente para una web. El usuario quiere ofrecer una web a un negocio concreto.
- disenar-sistema-ia: Diseñar un sistema de IA (agente o RAG). Hay que montar un asistente, un agente con herramientas o un buscador sobre documentos. [pendiente de prueba]
- elegir-modelo-local: Elegir un modelo local para el Mac del usuario. Hay que decidir si un modelo cabe en el Mac Studio M4 Max (36 GB) y cómo cargarlo. [pendiente de prueba]
- evaluar-agente: Evaluar a Sony u otro agente tras un cambio (no al usuario: para él, perfil-de-fortalezas). [pendiente de prueba]
- explicar-concepto-ia: Explicar un concepto de IA. El usuario pregunta qué es o cómo funciona algo de IA (transformer, LoRA, RAG, cuantización…). [pendiente de prueba]
- facturas-y-cuentas: Facturas, presupuestos y cuentas del mes (IVA 21 %). Hay que preparar un presupuesto o una factura, o poner orden en ingresos y gastos.
- find-skills: Buscar skills nuevas en skills.sh cuando el usuario pregunta «¿hay alguna skill para…?». Sony busca y recomienda; instalar lo hace el usuario con ~/IA/sony/instalar-skill.sh. [pendiente de prueba]
- montar-video-corto: «Hazme un corto con mis vídeos»: monta un vídeo vertical con trozos, imágenes y textos (no publica).
- guion-video-corto: Guion de vídeo corto (TikTok/Reels/Shorts). Hay que grabar un vídeo de 15-60 s.
- capturar-idea: Guardar una idea suelta del usuario en segundos en ideas/bandeja. «Tengo una idea», «apunta esto».
- desarrollar-idea: Convertir una idea en un plan pequeño con primer paso de hoy. «Desarrolla esta idea», «¿qué te parece…?».
- revision-semanal: Revisión semanal de 15 minutos: ideas, proyectos, redes y aprendizaje, y 3 prioridades.
- idea-producto-digital: Idear un producto digital rentable. Buscar nuevas fuentes de ingresos con lo que el usuario ya sabe hacer.
- investigar-tema: Investigar un tema en internet. El usuario pregunta algo que necesita fuentes actuales.
- landing-rapida: Crear una landing page rápida. Hace falta una página de una sola pantalla para un producto o cliente.
- plan-contenidos-redes: Plan de contenidos para redes. Hay que planificar publicaciones (tu proyecto, un cliente…).
- plan-negocio-una-pagina: Plan de negocio en una página. El usuario tiene una idea nueva y quiere ver si tiene sentido.
- presupuesto-web: Presupuestar una web. Hay que dar precio a una web o a un cambio.
- prueba-de-ataques: Prueba de seguridad de Sony con ataques simulados, solo en este Mac y con datos falsos. El script aún no está en el Mac. [pendiente de prueba]
- resumen-reunion: Resumir una reunión o una clase. Hay una grabación o transcripción (un .txt o .md que el usuario sube al chat).
- revisar-codigo: Revisar código de un proyecto. Antes de publicar una versión o tras un cambio grande.
- textos-venta-correos: Textos de venta y correos comerciales. Hay que escribir un texto comercial: correo, mensaje, descripción de servicio o anuncio.

## Redes y segundo cerebro
- publicar-en-redes: Publicar un post en las redes del usuario con tarjeta por cada post. Úsala cuando el usuario diga «publica», «sube» o «pon esto en X/LinkedIn/Reddit». [pendiente de prueba]
- post-x: Escribir posts y hilos para X (280 caracteres). Úsala para cualquier publicación en X. [pendiente de prueba]
- post-linkedin: Escribir publicaciones de LinkedIn (hasta 3000 caracteres), tono profesional y cercano. [pendiente de prueba]
- post-reddit: Publicar en Reddit respetando las normas del subreddit y diciendo que es un producto del usuario. [pendiente de prueba]
- borrador-instagram-tiktok: Preparar borradores para Instagram y TikTok (no publican solas): texto, guion y checklist de subida. [pendiente de prueba]
- adaptar-contenido-a-redes: Convertir una idea o texto en versiones para varias redes. [pendiente de prueba]
- calendario-semanal-redes: Planificar la semana de publicaciones y guardarla en el segundo cerebro. [pendiente de prueba]
- revisar-redes-semana: Repasar lo publicado en la semana y decidir qué mejorar. [pendiente de prueba]
- guardar-en-segundo-cerebro: Guardar una idea, decisión o aprendizaje como nota en el segundo cerebro. [pendiente de prueba]
- buscar-en-segundo-cerebro: Encontrar información en el segundo cerebro antes de responder sobre el usuario, sus proyectos o sus redes. [pendiente de prueba]

## Aprendizaje (inglés y desarrollo web)
- ingles-prueba-de-nivel: Hacer la prueba de nivel de inglés del usuario (de A1 a C1) y guardar su perfil. Úsala la primera vez o cuando pida «mi nivel». [pendiente de prueba]
- ingles-conversacion: Practicar conversación en inglés con el usuario: charlas a su nivel con correcciones al final. Úsala para «practiquemos inglés» o «hablemos en inglés». [pendiente de prueba]
- ingles-ejercicios: Hacer ejercicios de inglés con corrección: vocabulario, gramática, huecos, traducción y escritura. Úsala para «ponme ejercicios» o tras una conversación. [pendiente de prueba]
- ingles-repaso: Repasar lo aprendido: vocabulario y errores pasados con repetición espaciada. Úsala cada pocos días o cuando el usuario pida «repasar». [pendiente de prueba]
- ingles-pronunciacion: Practicar pronunciación en inglés: frases para repetir, sonidos difíciles para hispanohablantes y trucos. Úsala para «mejorar mi pronunciación». [pendiente de prueba]
- ensenar-programacion: Enseñar programación desde cero al usuario (Python y JavaScript) paso a paso, con ejercicios y proyectos. Úsala para «enséñame a programar». [pendiente de prueba]
- ensenar-ia: Enseñar ingeniería de IA al usuario: cómo funcionan los modelos, prompts, RAG, agentes, evaluación y modelos locales. Úsala para «enséñame IA». [pendiente de prueba]
- ensenar-ordenadores: Enseñar cómo funcionan los ordenadores al usuario: terminal, archivos, Git, redes, seguridad y qué hace el sistema. Úsala para «enséñame de ordenadores». [pendiente de prueba]
- ensenar-desarrollo-web: Enseñar desarrollo web (HTML, CSS, JavaScript) al usuario paso a paso, con ejemplos, ejercicios y proyectos. Úsala para «enséñame web» o «sigamos con el curso». [pendiente de prueba]

- perfil-de-fortalezas: «Evalúame», «mi CI/coeficiente», «qué se me da bien»: perfil de fortalezas del usuario con retos (nunca da un CI). [pendiente de prueba]
- mejorar-prompt: Escribir o mejorar prompts para otras IA (ChatGPT, Claude, generadores de imagen y vídeo). Úsala para «hazme un prompt», «mejora este prompt» o «qué le pido a la IA». [pendiente de prueba]
