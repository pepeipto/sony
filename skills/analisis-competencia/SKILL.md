# Analizar la competencia

**Cuándo usarla:** Antes de lanzar algo o para mejorar un producto.

**Pasos:**
1. Listar 3-5 competidores (búsqueda web).
2. Comparar precio, funciones, público, puntos fuertes y débiles.
3. Detectar huecos que nadie cubre.
4. Proponer 3 mejoras priorizadas (como el estudio de competencia de tu proyecto).

**Qué entrega:** tabla comparativa + 3 recomendaciones.

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
