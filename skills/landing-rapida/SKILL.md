# Crear una landing page rápida

**Cuándo usarla:** Hace falta una página de una sola pantalla para un producto o cliente.

**Pasos:**
1. Pedir nombre, qué ofrece, a quién y la llamada a la acción.
2. Estructura: héroe con título y botón, 3 beneficios, prueba social, preguntas frecuentes, contacto.
3. HTML y CSS en un solo archivo, móvil primero, sin dependencias externas.
4. Verla como artefacto y entregar el archivo.

**Qué entrega:** index.html listo para alojar (Cloudflare Pages o GitHub Pages).

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
