# Resumir una reunión o una clase

**Cuándo usarla:** Hay una grabación o transcripción (por ejemplo un .txt o .md que el usuario sube al chat).

**Pasos:**
1. Leer la transcripción por partes.
2. Sacar decisiones, tareas (quién y cuándo) y dudas abiertas.
3. Resumen de 5-10 líneas al principio.
4. Proponer guardarlo como nota del cerebro con enlaces al proyecto.

**Qué entrega:** resumen + lista de tareas + nota lista para el cerebro.

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
