# Analizar una hoja de cálculo o de ventas

**Cuándo usarla:** el usuario comparte una hoja (Google Sheets o CSV) y quiere entenderla.

**Pasos:**
1. Leer la hoja (sheets_leer o archivo) y describir columnas, filas y periodo.
2. Comprobar calidad: vacíos, duplicados, fechas raras.
3. Calcular lo básico: totales, medias, evolución por mes, top productos/clientes.
4. Sacar 3 conclusiones con números y 2 acciones recomendadas.
5. Si hace falta una gráfica, proponerla como artefacto.

**Qué entrega:** resumen con cifras clave, conclusiones y acciones.

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
