# Diseñar una automatización con n8n

**Cuándo usarla:** Una tarea repetitiva que se puede automatizar.

**Pasos:**
1. Describir disparador, datos de entrada y resultado esperado.
2. Elegir nodos (Webhook/Schedule → lógica → acción) y credenciales mínimas.
3. Añadir manejo de errores e idempotencia.
4. Probar con datos falsos y dejar el flujo desactivado hasta que el usuario lo apruebe.

**Qué entrega:** esquema del flujo, lista de credenciales necesarias y JSON exportable.

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
