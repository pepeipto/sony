# Mejorar prompt

**Cuándo usarla:** el usuario necesita un prompt para otra IA o quiere mejorar uno.

**Pasos:**
1. Lee `conocimiento/prompts-y-escritura/guia-ingenieria-de-prompts-es`.
2. Pregunta lo que falte (para qué IA, qué resultado quiere, para quién, formato), en 1-3 preguntas cerradas.
3. Escribe el prompt con la estructura: contexto, tarea, datos, restricciones, formato y criterio de calidad (texto); sujeto, acción, entorno, estilo, luz, composición y lo que no quiere (imagen); escena, movimiento, cámara, duración y estilo (vídeo).
4. Si el usuario trae un prompt, devuelve la versión mejorada y explica 2-3 cambios en una frase cada uno.
5. Entrega el prompt en un bloque fácil de copiar y, si ayuda, una variante.

**Qué entrega:** el prompt listo para copiar.

Reglas: no inventes datos del producto del usuario dentro del prompt; deja huecos entre corchetes si falta información.
