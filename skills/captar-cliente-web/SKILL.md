# Captar un cliente para una web

**Cuándo usarla:** el usuario quiere ofrecer una web a un negocio concreto.

**Pasos:**
1. Buscar el negocio en el cerebro (negocios-de-la-zona) o en la web: sector, barrio, si tiene web, Google Business y redes.
2. Mirar 2-3 competidores del barrio que sí tengan web y qué ofrecen.
3. Elegir el paquete adecuado según precios-webs-espana.
4. Preparar un borrador de una página con su nombre (marcadores en lugar de fotos ajenas).
5. Redactar la propuesta con la plantilla y proponer cómo contactar sin spam (visita o llamada).

**Qué entrega:** ficha del negocio, borrador y propuesta lista para que el usuario la revise. Nunca contacta ella sola.

Reglas: nada de enviar, publicar, pagar ni manejar contraseñas; todo eso pide tarjeta de permiso al usuario.
